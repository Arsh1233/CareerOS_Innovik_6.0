# Global Design Prompt

> Design a futuristic, premium SaaS web application called "CareerOS". The theme should use dark mode with gradients of deep black (#0B0F19), electric blue (#3B82F6), and neon purple (#8B5CF6). Use glassmorphism, subtle particle effects, animated backgrounds, holographic cards, and smooth micro-interactions. The UI should feel like a mix of Apple, Linear, Vercel, and Iron Man's JARVIS. Use Poppins and Inter fonts. Include AI-themed illustrations, glowing buttons, floating cards, and responsive layouts. Every screen should look investor-ready and suitable for an Agentic AI startup.
